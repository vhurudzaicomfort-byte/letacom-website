# Letacom (Pty) Ltd website

Official website for Letacom (Pty) Ltd (Reg. No. 2023/189890/07), https://letacom.co.za.

Next.js (App Router) + TypeScript + Tailwind CSS + Lucide icons, deployed on Vercel.

- Company details: `lib/site.ts`
- Services: `lib/services.ts`
- FAQs: `lib/faqs.ts`
- Enquiry API: `app/api/contact/route.ts` (env vars in `.env.example`)

Images: Pexels (free licence, https://www.pexels.com/license/).

```bash
npm install
npm run dev
npm run build
```
